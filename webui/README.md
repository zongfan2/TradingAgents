# TradingAgents Web UI

Robinhood 风格的本地前端：看行情、发起多智能体分析、读分层报告，并在 Settings 里配置
部署这个库所需的全部依赖项。

## 启动

```bash
.venv/bin/uvicorn webui.server:app --port 8321
```

打开 http://localhost:8321 。仅监听本地，不做鉴权——按本地单用户工具设计，不要暴露到公网。

## 功能

**行情主卡**：大字报价 + 涨跌幅、绿/红趋势图（十字线悬停显示日期与价格）、1周/1月/3月/1年切换。

**多智能体分析**：选日期 → 一键发起 → 五阶段流水线指示 + 实时日志（含新闻分析师的自主搜索
query）→ 决策徽章（增持/持有/减持）+ 完整决策书 + 分层报告标签页（技术面/情绪/新闻/基本面/
多空/研究经理/交易员/风险三方/最终决策）。同一时间只允许一个分析运行（第二次请求返回 409）。

**自选与历史**：自选列表存本地浏览器，实时报价；历史报告按时间倒序，点击即可回看。

## Settings 可配置项

| 分组 | 内容 |
|---|---|
| LLM | provider（19 家）、deep/quick 模型（按 provider 给建议值）、backend URL（可指向本地订阅代理或任何 OpenAI 兼容端点）、OpenAI/Claude/Gemini 推理强度、temperature |
| API Keys | 20 个环境变量（各家 LLM + Alpha Vantage + FRED + OLLAMA_BASE_URL） |
| 数据源 | 六个类别各自选 vendor（yfinance / alpha_vantage / 逗号分隔的 fallback 链 / default） |
| 流水线 | 辩论轮数、风险轮数、报告语言、checkpoint 断点续跑 |

**密钥处理**：`GET /api/config` 只返回每个 key 是否已配置的布尔值，**从不回显 key 值**；
输入框留空表示保留现值。保存时双写仓库根目录 `.env`（与 CLI、`compare/run.py` 共享同一份
配置）和 `webui/settings.json`（存 vendor 选择）。清空某项设置会**删除**对应的 `.env` 行，
而不是留下旧值继续生效。

## 已知边界

- **进度指示的精度**：只有分析师阶段会输出可识别的日志（数据源路由、自主搜索 query），
  后续研究/交易/风险/组合节点不打日志，因此这四步显示为"进行中"的不确定态，而不是假装
  精确到某一步。
- **报告渲染**：内置极简 markdown 渲染器，先转义再解析，链接只允许 `http(s)` 且不含引号；
  报告是 LLM 对新闻/社交等外部内容的转述，属不可信输入，所以不支持内联 HTML。
- 分析运行在服务进程的后台线程里，重启服务会中断进行中的分析（磁盘上的历史报告不受影响）。
